AKRUTI GUPTA — YOUR PORTFOLIO

QUICKEST WAY TO VIEW IT
1. Extract this ZIP completely (do not open the website inside the ZIP).
2. Open the akruti-portfolio folder.
3. Open dist/index.html in Chrome, Edge, Firefox or Safari.
   All five case studies and the navigation are included.
   No installation or internet connection is needed for the local pages.
   Resume, social and video links open external services and need internet.

TO EDIT YOUR CONTENT
1. Install Node.js 20 or newer if it is not already installed.
2. Open the akruti-portfolio folder in a code editor.
3. Edit src/content.mjs for project descriptions, dates, experience,
   your email and resume link. Homepage copy lives in scripts/build.mjs.
4. Open a terminal in that folder and run:

   npm run build
   npm run check

5. Refresh dist/index.html in your browser to see the changes.

No npm install is required: the project has no package dependencies.
The dist folder is regenerated by the build. Edit source files, not dist.

OPTIONAL LOCAL WEB SERVER
If Python 3 is installed, run npm run preview, then open:
http://127.0.0.1:4173/
On Windows, if python3 is not recognised, run:
py -m http.server 4173 --bind 127.0.0.1 --directory dist
Keep that terminal open while browsing; press Ctrl+C to stop the server.
